## Usage

```tsx
import {
    List,
    ListItem,
    ListItemContent,
    ListItemLabel,
    ListItemLeading,
    ListItemSupportingText,
    ListItemTrailing,
    ListItemTrailingText,
} from '@/components/ui/list'
```

```tsx
<List>
    <ListItem onClick={() => {}}>
        <ListItemLeading>
            <i className='icon-[material-symbols--content-copy-outline-rounded]' />
        </ListItemLeading>
        <ListItemContent>
            <ListItemLabel>Copy</ListItemLabel>
            <ListItemSupportingText>Copy the selection</ListItemSupportingText>
        </ListItemContent>
        <ListItemTrailing>
            <ListItemTrailingText>⌘C</ListItemTrailingText>
            <i className='icon-[material-symbols--arrow-right-rounded]' />
        </ListItemTrailing>
    </ListItem>
</List>
```

An item becomes interactive when it has an `onClick` handler or uses `asChild`.

## Segmented

`variant='segmented'` separates items with a small gap and rounds the outer corners of the list. Place it on a `surface-container` background.

    <ListSegmentedDemo />
</ComponentPreview>

## Lines

Add `ListItemOverline` and `ListItemSupportingText` for two-line items. Set `lines={2}` on `ListItemSupportingText` for three-line items.

<ComponentPreview>
    <ListLinesDemo />
</ComponentPreview>

## Selection

Set `selectable` to let the item toggle its own selection. Control it with `selected` and `onSelectedChange`, or use `defaultSelected`.

<ComponentPreview>
    <ListSelectionDemo />
</ComponentPreview>

## Leading elements

`ListItemLeading` holds an icon, avatar, image, video thumbnail, checkbox, radio button, or switch. In a `selectable` item, controls inside become inert and the item handles clicks, so pass them the same state as `selected`.

<ComponentPreview>
    <ListLeadingDemo />
</ComponentPreview>

## Trailing elements

`ListItemTrailing` holds trailing supporting text, icons, a checkbox, radio button, or switch.

<ComponentPreview>
    <ListTrailingDemo />
</ComponentPreview>

## Expandable

`ListCollapsible` groups a trigger item with nested items. `ListCollapsibleIndicator` shows a chevron that flips when expanded.

<ComponentPreview>
    <ListCollapsibleDemo />
</ComponentPreview>

## Reorder

Pass `onReorder` to `List` and add a `ListItemDragHandle` to each item. Drag the handle, or focus it and press <kbd>↑</kbd> and <kbd>↓</kbd>, to move the item. Reorder works on the direct children of the list.

<ComponentPreview>
    <ListReorderDemo />
</ComponentPreview>

## Swipe actions

Wrap an item in `ListItemReveal` to reveal actions when it is swiped left. Add a `ListItemRevealTrigger` to open and close the actions from a more button, and use `open` and `onOpenChange` to control it. Give icon-only actions a `label`.

## API Reference

### List

| Prop      | Type                                 | Default    |
| :-------- | :----------------------------------- | :--------- |
| variant   | `standard` \| `segmented`            | `standard` |
| onReorder | `(from: number, to: number) => void` |            |

All other div props are forwarded.

### ListItem

| Prop             | Type                          | Default                                           |
| :--------------- | :---------------------------- | :------------------------------------------------ |
| selectable       | `boolean`                     | `false`                                           |
| selected         | `boolean`                     |                                                   |
| defaultSelected  | `boolean`                     | `false`                                           |
| onSelectedChange | `(selected: boolean) => void` |                                                   |
| disabled         | `boolean`                     | `false`                                           |
| dragged          | `boolean`                     | `false`                                           |
| interactive      | `boolean`                     | `true` with `selectable`, `onClick`, or `asChild` |
| asChild          | `boolean`                     | `false`                                           |

### ListItemSupportingText

| Prop  | Type       | Default |
| :---- | :--------- | :------ |
| lines | `1` \| `2` | `1`     |

### ListCollapsible

| Prop         | Type                      | Default |
| :----------- | :------------------------ | :------ |
| open         | `boolean`                 |         |
| defaultOpen  | `boolean`                 | `false` |
| onOpenChange | `(open: boolean) => void` |         |

`ListCollapsibleTrigger` merges its props into its child `ListItem`. `ListCollapsibleContent` holds the nested items.

### ListItemReveal

| Prop         | Type                      | Default |
| :----------- | :------------------------ | :------ |
| actions      | `React.ReactNode`         |         |
| open         | `boolean`                 |         |
| defaultOpen  | `boolean`                 | `false` |
| onOpenChange | `(open: boolean) => void` |         |
| actionWidth  | `number` (px, per action) | `48`    |

### ListItemRevealAction

| Prop    | Type                | Default |
| :------ | :------------------ | :------ |
| variant | `tonal` \| `filled` | `tonal` |
| label   | `string`            |         |

### ListItemRevealTrigger

| Prop  | Type     | Default        |
| :---- | :------- | :------------- |
| label | `string` | `More actions` |

Renders a more icon unless you pass children.

### ListItemDragHandle

| Prop  | Type     | Default   |
| :---- | :------- | :-------- |
| label | `string` | `Reorder` |

`ListItemLeading`, `ListItemContent`, `ListItemOverline`, `ListItemLabel`, `ListItemTrailing`, `ListItemTrailingText`, and `ListCollapsibleIndicator` accept their element's props.
