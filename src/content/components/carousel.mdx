## Usage

```tsx
import { Carousel, CarouselItem, CarouselItemLabel } from '@/components/ui/carousel'
```

```tsx
<Carousel>
    <CarouselItem>
        <img src='/photo.jpg' alt='' className='size-full object-cover' />
        <CarouselItemLabel className='text-white'>Mountains</CarouselItemLabel>
    </CarouselItem>
    ...
</Carousel>
```

`CarouselItemLabel` follows the visible part of its item and inherits the text color, so add `text-white` over photos. Pass `onClick` to `CarouselItem` to make it interactive.

On vertically scrolling pages, add a way to view every item without scrolling sideways, such as a **Show all** button below the carousel.

Set `width` on each `CarouselItem` in an uncontained carousel to mix item widths, from 9:16 up to 16:9.

## Full screen

`full-screen` shows one edge-to-edge item at a time, scrolling vertically. It works best for portrait content.

<ComponentPreview>
    <CarouselFullScreenDemo />

## Sizing

In `multi-browse`, `hero`, and `center-hero`, the carousel picks how many large, medium, and small items fit, keeping the large width close to `itemWidth`. Set the carousel height with `className`.

## API Reference

### Carousel

| Prop      | Type                                                                          | Default             |
| :-------- | :---------------------------------------------------------------------------- | :------------------ |
| layout    | `multi-browse` \| `hero` \| `center-hero` \| `uncontained` \| `full-screen` | `multi-browse`      |
| itemWidth | `number` (max large item width, or item width when uncontained, in px)        | depends on `layout` |
| className | `string`                                                                      |                     |

All other div props are forwarded to the scroll container.

### CarouselItem

| Prop      | Type                        | Default     |
| :-------- | :-------------------------- | :---------- |
| width     | `number` (uncontained only) | `itemWidth` |
| onClick   | `React.MouseEventHandler`   |             |
| className | `string`                    |             |

### CarouselItemLabel

Accepts all div props.
