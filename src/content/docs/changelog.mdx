## 2026-09-30

- **Added:** [Toolbar](/components/toolbar) with floating, docked, vertical, and compact layouts.
- **Changed:** [Button](/components/button) and [Toggle](/components/toggle) styling for [Toolbar](/components/toolbar) integration. Update them together when composing toolbar actions.

## 2026-07-27

- **Fixed:** [Context Menu](/components/context-menu) and [Dropdown Menu](/components/dropdown-menu) corner radii, including compact menus.
- **Fixed:** Nested interaction-state conflicts in [Button](/components/button), [Card](/components/card), [Checkbox](/components/checkbox), [Chip](/components/chip), [Navigation Rail](/components/navigation-rail), [Radio Group](/components/radio-group), [Snakebar](/components/snakebar), [Switch](/components/switch), [Text Field](/components/text-field), and [Toggle](/components/toggle).

## 2026-05-02

- **Added:** [Popover](/components/popover).
- **Added:** A [Calendar](/components/calendar) date-picker example; no [Calendar](/components/calendar) component changes.

## 2026-05-01

- **Added:** [Calendar](/components/calendar) with single/range selection, input pickers, and action buttons.
- **Fixed:** [Calendar](/components/calendar) locale handling and TypeScript compatibility.

## 2026-04-30

- **Changed:** [Search](/components/search) button and icon styling support. Clearing an empty search now closes it.

## 2026-04-29

- **Added:** [Search](/components/search) with docked and fullscreen layouts.
- **Changed:** [Slider](/components/slider) with more sizes, centered tracks, stops, value indicators, and icons. Range sliders now require two explicit values.
- **Changed:** [Loading](/components/loading) shape sizing and rotation for smoother transitions.
- **Added:** Optional [Switch](/components/switch) icons and press transitions.
- **Added:** Compact mode for [Context Menu](/components/context-menu) and [Dropdown Menu](/components/dropdown-menu).

## 2026-01-31

- **Changed:** [Ripple](/components/ripple)'s initial animation scale.

## 2026-01-29

- **Changed:** [Ripple](/components/ripple) scale and gradient.
- **Fixed:** Unwanted outline on the [Navigation Rail](/components/navigation-rail) modal.

## 2026-01-27

- **Added:** Custom child composition for [Card](/components/card).
- **Changed:** [Loading](/components/loading) no longer requires Motion.
- **Fixed:** [Text Field](/components/text-field) padding and floating-label alignment.

## 2026-01-22

- **Added:** Improved child composition for [Button](/components/button), [Chip](/components/chip), [Navigation Bar](/components/navigation-bar), [Navigation Rail](/components/navigation-rail), and [Tabs](/components/tabs).
- **Changed:** [Navigation Rail](/components/navigation-rail) configuration and menu layout. Review its current usage when upgrading.
- **Fixed:** [Button Group](/components/button-group) rounding and [Tabs](/components/tabs) heights.

## 2026-01-21

- **Changed:** [Navigation Rail](/components/navigation-rail) menus and actions now use explicit composition.
- **Fixed:** [Navigation Rail](/components/navigation-rail) trigger behavior and item property forwarding.
- **Changed:** [Navigation Bar](/components/navigation-bar) and [Navigation Rail](/components/navigation-rail) label alignment and spacing.

## 2026-01-20

- **Changed:** Split navigation into separate [Navigation Bar](/components/navigation-bar) and [Navigation Rail](/components/navigation-rail) components. Existing integrations need updated imports and composition.

## 2026-01-19

- **Fixed:** Medium [Button](/components/button) and [Toggle](/components/toggle) padding.
- **Fixed:** [Checkbox](/components/checkbox) icon color and [Context Menu](/components/context-menu) icon spacing.

## 2026-01-17

- **Changed:** [Badge](/components/badge), [Button](/components/button), [Checkbox](/components/checkbox), [Chip](/components/chip), [Context Menu](/components/context-menu), [Dialog](/components/dialog), [Dropdown Menu](/components/dropdown-menu), [Snakebar](/components/snakebar), [Tabs](/components/tabs), [Text Field](/components/text-field), and [Toggle](/components/toggle) migrated from Lucide to Iconify. Follow the [installation guide](/docs/installation) when updating icons.
- **Fixed:** [Text Field](/components/text-field) placeholders without labels and the [Checkbox](/components/checkbox) check icon.

## 2026-01-14

- **Changed:** [Text Field](/components/text-field) borders, floating labels, and icon layout.

## 2026-01-13

- **Added:** [Avatar](/components/avatar) and [Chip](/components/chip).
- **Changed:** [Button](/components/button) child composition was temporarily removed, then restored on January 22.
- **Fixed:** [Context Menu](/components/context-menu) and [Dropdown Menu](/components/dropdown-menu) icon colors.

## 2026-01-12

- **Changed:** [Loading](/components/loading)'s animation dependency, later removed on January 27.
- **Fixed:** [Ripple](/components/ripple) compatibility with React Server Components.

- **Changed:** [Button](/components/button), [Toggle](/components/toggle), and [Ripple](/components/ripple) corner handling and large-button icon sizes. Update these components together.
